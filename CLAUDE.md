# Dual Origin Group — landing page

One-screen landing page for **dualorigingroup.com**, served by GitHub Pages from `main` (root). Dual Origin Group LLC ("DOG LLC") is a two-partner consulting company (Sam & Gio, equal co-founders) building process-optimization and cost-analysis tools for general contractors and manufacturers.

## Files
- `index.html` — the whole page: HTML, CSS, inline SVG logo, animations. No build step.
- `images/cup.webp` (1236w), `cup-900.webp`, `cup-640.webp` — what browsers actually load (responsive `<picture>`, preloaded, `fetchpriority=high`). `images/cup.png` is the fallback. A ~1KB blurred copy is inlined in CSS as the `.cupbox` background so the cup outline appears instantly; JS removes it on load.
- `images/cup.png` — the to-go cup contact card as ONE flattened image (lid, sleeve, classic maroon badge stamp, and a slightly tilted paper receipt pinned to the sleeve by the stamp: Sam and Gio's large color photos (66×72 in the source) side by side as unframed prints on warm cream `#EFE6D8` (cropped head-and-shoulders down to the bottom of the original photos so collars show), slightly tilted toward each other, each held by a strip of kraft tape (`#B98A5C`, 60% opacity) straddling its top edge, names "SAM" / "GIO" in bold spaced monospace under them, and a copper espresso-cup email icon on each photo; dashed tear line; corgi line item "PAO PAO" (the corgi's name, bold spaced monospace) / "HEAD OF SECURITY" / "Guards the beans" x1, with the text vertically centered beside the photo (the bubbles sit to the left, so nothing on the receipt needs to move for them); footer "BREWED IN MA" with a small flag hung beside it at cap height (the text stays centered) / smaller "© 2026 DOG LLC"). 1236×1428. The speech bubble is NOT in this image.
- `images/bubble.webp` / `bubble.png` — the corgi's cartoon speech bubble reading "Call us!" above the phone number (image only): white blob, bold dark outline, sitting to the LEFT of the corgi with a short chunky comic tail pointing sideways to its mouth; it may extend past the cup's left edge (it lives in `.names`, outside the receipt's clip-path). Hidden until the stamp's inner circle (LET'S TALK + phone icon) is clicked: `<button class="telbtn">` toggles `<img id="bub" class="bubimg">` (pop-in from the tail; closes on outside click or Escape). The bubble itself is not clickable (no enlarge, no dialer). The bubble images are lazy-loaded (`data-src`/`data-srcset`) on first use, so they are not fetched on page load. The phone number is never in HTML/JS, not even scrambled: tap-to-call is intentionally not implemented. The email addresses are NOT shown in the image; the espresso icons are the only way to email.
- Corgi message bubble (`.bubmsg`, live HTML text over the same bubble outline, same left-side short-tail shape, 1.45× the phone bubble's width on desktop and 1.22× on phones (≤600px, via a media query) so it never touches the screen edge; after any cup rebuild re-anchor it from the `.bubimg` box keeping the same tail tip): when an espresso email button is clicked, the corgi says "Fetched / {Name}'s email!" then pops out and back in with "Special / delivery!" (~1.7s + ~2.2s), then pops out. If the clipboard copy fails it only says the second line. The copy happens immediately on click, but `mailto:` is opened only after the corgi has spoken (~2.3s, or ~0.9s when only the second line shows) so visitors actually see the bubbles; repeat clicks reset the timer. Text never includes an address. The text is mirrored into the hidden `.toast` live region for screen readers. Opening the phone bubble hides it, and vice versa. Keep messages to two short lines (~13 characters each) or they overflow on phones.
- `images/wordmark-light.png` — "DUAL ORIGIN GROUP" wordmark (Lora, cream, D/O/G slightly brighter).
- `images/corgi.png` — corgi cutout (the badge itself is now baked into `cup.png`).
- `images/steam-1..3.png` — steam textures for the rising-steam animation.
- `CNAME` — custom domain. **Never delete.** `.nojekyll` — serve files as-is.

## Hard rules
1. **Fits on one screen, no scrolling**, at common sizes: 375×667, 390×664, 390×844, 430×932, 768×1024, 1280×720, 1366×768, 1440×900, 1920×1080. Check `document.documentElement.scrollHeight === innerHeight` after every change (Playwright/headless Chrome). Also no scrolling at ANY size, including short laptop windows and landscape phones: run `node tools/fitscan.js` in `website-assets` (376 viewports, 320–2560 wide, 320–1440 tall; must report 0 overflow). Short screens use compact header/text bands: `max-height:619px` (`--k:236px`) and `max-height:460px` (`--k:144px`); the cup can shrink to 96px wide.
2. **No readable contact info in the code.** The phone number is shown only as an image (the speech bubble); emails are reachable only through the espresso-cup icons (anti-scraping). Never put a plain-text email, phone number, or literal `mailto:<address>` in HTML, alt text, metadata or JS. The ONE exception (approved by the owners): the two espresso-cup email icons on the portraits are `<button class="mailbtn">` hotspots whose script holds each address XOR-scrambled and reversed, assembles it only on click, copies it to the clipboard, and opens `mailto:`. The phone number has no such exception. This repo is public: audit with `git log --all -p` before adding anything contact-related. Past versions of `cup.png` and the bubble images (contact info rendered as pictures) remain in git history; that is accepted (image-only), but never add contact text to commit messages, PR bodies or docs.
3. **Dark mode only.** No light theme or toggle.
4. Sam and Gio are **equal partners**: always side by side / shared, never one above the other.
5. Animations stay subtle and respect `prefers-reduced-motion`.

## Design system
- Colors: bg `#1A1310`, ink `#F3E7DA`, muted `#BFAE9F`, copper accent `#C8692A`, line `#3A2C24`, card `#241A15`. Stamp: solid classic maroon `#6B1E2A` badge with cream `#F7F1E6` lettering (was sage green `#2F5D46`, and before that a rust ink stamp).
- Fonts: Lora (headline, wordmark), Inter (body/UI), via Google Fonts.
- Layout top→bottom: two-bean logo (per-bean jiggle) + wordmark + "CONSULTANTS" → h1 "Bottlenecks brewing?" → 3-line blurb (fixed line breaks via `.tag .l` spans, `white-space:nowrap`) → cup image with beans funneling in and steam behind. There is no page footer: "Brewed in MA" and the copyright are printed on the receipt inside the cup image.
- Blurb lines (keep these breaks): "We build custom solutions that surface the" / "right information and keep work flowing," / "so your team can make better calls, faster."
- Receipt (`.rc` in the source): clean white paper `#FFFFFF` with only a faint grain (no crumple/fold/aging), straight sides, a thin dark outline tracing its zigzag edges (drop-shadow on the `.names` wrapper, since the receipt's own clip-path would cut it off), zigzag top/bottom, monospace text, tilted −2°. Corgi is a receipt line item (dog never "drinks" coffee — caffeine is toxic to dogs). The phone number appears in a speech bubble from the corgi only after clicking the stamp. The old name tape and separate badge markup remain in the source but are hidden. No "CO-FOUNDERS" label.
- Sleeve: starts ~55px below the rim (a white cup band above it) and ends at the middle of the corgi row (~254px tall), leaving white cup below it. Its top edge sits just under the stamp's DUAL ORIGIN GROUP arc, so most of the stamp is on kraft. The stamp (~152px) is a classic coffee-house badge: solid maroon disc, thin cream double ring, heavy slab-serif lettering (Alfa Slab One, loaded only in the private source), stars at the sides, lightly weathered (subtle ink unevenness, sparse small chips, softened edges; lettering stays crisp). Its top stops just below the lid and it pins the receipt's top edge, staying clear of the photos. No logo/emblem inside the badge.
- Stamp text: "DUAL ORIGIN GROUP" top arc, "EST. 2026" bottom arc, "LET'S TALK" in the inner circle with a small outlined phone icon under TALK (clicking the inner circle reveals the corgi's speech bubble; it does not call).

## CSS note
`index.html` has many appended override blocks at the end of `<style>` (with `!important`) from iterative design. Later rules win. When changing sizing, prefer adding/adjusting the media-query blocks near the end rather than editing early rules. Spacing rhythm is set by the LAST block ("consistent vertical rhythm"): `main/.wrap/.copy` are `display:contents`, three `<i class="sp">` spacers (logo→h1, blurb→lid, cup→bottom of page) flex in body's column, and the cup width `--cw` grows with screen height up to `--cap`. Tune per breakpoint via `--k` (height reserved for everything except the cup), `--g` (base gap) and `--glogo` (logo gap, gets 2 shares of leftover). h1→blurb stays a fixed 10px. If a change makes the header/text taller, raise `--k` for that band or the page will scroll.

## Regenerating the cup image
`cup.png` is rendered from a private HTML source (not in this repo because it contains the contact text). The source kit lives in the **private** repo `dualorigingroup/website-assets` (`cup-source.html`, `tools/cupshot.js`, README with steps); attach it to the session to edit the cup. Never copy its contents into this public repo. Process: open the source HTML in headless Chrome at 1440×900, deviceScaleFactor 4, hide everything except the cup (lid, cup body, sleeve, stamp, names), disable animations and any glow/pseudo-elements, screenshot the bounding box of the visible `.lid,.cta,.kraft,.names,.tape,.cb,.bub,.rc` (zero-size/hidden elements are skipped) with 24px transparent padding (`node tools/cupshot.js` in `website-assets` does all of this; it waits for web fonts and refuses to render if Alfa Slab One didn't load) and `omit_background`, resize to 1236px wide, save as `images/cup.png`, then update the `height` attribute on `<img class="cupimg">`, regenerate `cup.webp`/`cup-900.webp`/`cup-640.webp` (quality 82, alpha 90) and the inlined blurred placeholder (32px wide, WebP data URI in the `.cupbox` rule). `node tools/cupshot.js cup-raw.png bubble-raw.png` writes the cup without the bubble plus the bubble alone, (it disables clip-paths while rendering the bubble, since the bubble extends past the cup's tapered clip), and prints positions as % of the cup image: email icons → `.mailbtn` `left`/`top`; stamp inner circle (`stamp` cx/cy/d) → `.telbtn` `left`/`top`/`width` (the tap area covers the whole LET'S TALK inner circle, not just the phone icon); bubble box → `.bubimg` `left`/`top`/`width`/`transform-origin` (the tail tip, from the bubble's `data-tip`). Resize the bubble by the same factor as the cup (1236 ÷ raw width). If the cup's height/width ratio changes, update the `/ 1.30` divisor in the `--cw` formula (visible cup height ÷ `.mugwrap` width) and re-tune `--k`. The image must have fully transparent edges so the page's glow fades smoothly.

## Cache busting
Every `images/...` reference in `index.html` carries `?v=<first 8 hex of the file's SHA-1>` so a changed image gets a new URL and browsers fetch it immediately (GitHub Pages caches files for ~10 min and that can't be changed). After changing ANY image, run `python3 tools/stamp-assets.py /path/to/website` from `website-assets`. It is idempotent and keeps the preload `imagesrcset` identical to the `<source srcset>` so the cup is still fetched once.

## Workflow
- Develop on the session's working branch; never push to `main` directly.
- After each change, republish the private preview artifact (https://claude.ai/artifact/KuAvVPuuUiJg3CMSHYxLaC) from a copy of `index.html` with the doctype/html/head/body wrapper tags removed, plus the `images/` files. Pass that URL to update it from a new session.
- Merge to `main` (via pull request) **only when the owner says "merge"**. Merging to `main` publishes the live site.
